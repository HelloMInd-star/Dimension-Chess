# ♟️ 星穹弈 · Dimension Chess

**星穹弈** 是一款融合了 **MBTI 人格牌组**、**筹码博弈** 与 **乐高棋盘** 的回合制策略游戏。

> 中文名：星穹弈 · 英文名：Dimension Chess · 简称：DC

---

## 🎮 游戏简介

在星穹弈中，你不再只是“走棋”——你是在用 **MBTI 人格牌** 下注，用 **筹码** 换取步数，在 **5×5 的乐高棋盘** 上与 AI 对手进行心理与策略的博弈。

- 🧬 **选牌**：从手牌中选择 MBTI 类型（INTJ / ESFP / INFP ...），每种牌有不同的步数兑换率。
- 💰 **下注**：投入筹码，换取行动步数。SP 牌跑得快，但代价更高。
- ♟️ **走棋**：在棋盘上移动你的“王”，吃掉对方棋子，最终抵达对手的王座。
- 🔄 **撤回**：走错一步？可以撤回，但撤回会留下“废墟格”——你的战场会越退越小。

## ✨ 核心特性

| 特性 | 说明 |
| :--- | :--- |
| **🧬 MBTI 牌组系统** | 16 种 MBTI 人格牌，分为 NT / NF / SJ / SP 四组，每组有不同的步数兑换率 |
| **💰 筹码经济系统** | 动态买入（5万 ~ 1000万 + 自定义），下注、吃子、撤回、盲注、底池全链路闭环 |
| **♟️ 乐高棋盘** | 5×5 网格，支持元素格、废墟格、积木堆叠（层数最高 5 层） |
| **🌌 星座守护星** | 12 星座 × 12 种主动技能（如白羊·烈焰冲锋、双鱼·梦境迷踪），消耗筹码激活 |
| **🌀 灵魂分路** | 4 种被动天赋（守护者/探路者/战略家/催化者），开局选定，整局生效 |
| **⏰ 皮质醇节律** | 每 5 回合切换一次全局修正（深度睡眠 / 晨间巅峰 / 午后低迷 / 夜间活跃） |
| **🎵 音乐情绪系统** | 可消耗筹码切换歌单，干扰对手决策；“炸裂时刻”让对手撤回费用翻倍 |
| **👑 动态庄家 & 盲注** | 每 3 小局抢庄一次，庄家支付盲注，平局时庄家获胜 |
| **🌓 深色/浅色模式** | 大厅 & 牌桌右上角一键切换 |
| **🎓 新手教学关** | 4×4 迷你棋盘，3 步引导通关，零基础上手 |

## 🎯 玩法速览

### 一局游戏的完整流程

```
开局买入（选择筹码档位）
    ↓
选择守护星 + 灵魂分路
    ↓
匹配 AI 对手
    ↓
【小局开始】
    ↓
庄家支付盲注 → 双方抽牌（3 张 MBTI 牌）
    ↓
【回合循环】
    ├── 选牌（点击手牌中的 MBTI 牌）
    ├── 下注（输入筹码数 → 获得步数）
    ├── 走棋（点击棋盘上的发光格子移动）
    ├── 可选：撤回（后退1步 / 退一半 / 全额撤回）
    └── 结束回合
    ↓
【胜负判定】
    ├── 到达对手王格 → 获胜
    ├── 吃掉对手王 → 获胜
    ├── 对手筹码归零 → 获胜
    └── 20 回合未分胜负 → 筹码多者胜
    ↓
【小局结算】获胜者获得底池 + 200万奖励 + 1 个“一心”
    ↓
每 3 小局 → 抢庄阶段（赢者续庄或轮换）
```

## 📜 游戏机制详解

### MBTI 牌组兑换率

| 组别 | MBTI 类型 | 兑换率 | 额外规则 |
| :--- | :--- | :--- | :--- |
| **NT（分析师）** | INTJ, INTP, ENTJ, ENTP | 1万筹码 = 2步 | 无额外消耗 |
| **NF（外交家）** | INFJ, INFP, ENFJ, ENFP | 1万筹码 = 1.5步 | 撤回费用永久减半 |
| **SJ（守护者）** | ISTJ, ISFJ, ESTJ, ESFJ | 1万筹码 = 1步 | 无额外消耗 |
| **SP（探索者）** | ISTP, ISFP, ESTP, ESFP | 1万筹码 = 3步 | 打出需额外消耗2万筹码 |

### 组合技（手牌检测，无需打出）

| 组合条件 | 触发奖励 |
| :--- | :--- |
| **对子**（同一 MBTI 类型两张） | 本回合额外 +1 步 |
| **同组**（两张同属 NT/NF/SJ/SP） | 本回合可斜向走 1 次 |
| **四功能连号**（NT+NF+SJ+SP 各一张） | 获得一次“全额撤回”机会 |

### 撤回系统

| 撤回方式 | 筹码消耗 | 额外代价 |
| :--- | :--- | :--- |
| **后退 1 步** | 3万/步 | 原格变为废墟格 |
| **退一半步数** | 8万（固定） | 退回路径全变废墟格 |
| **全额撤回** | 消耗 1 张 NF 牌 | 退回路径全变废墟格 |
